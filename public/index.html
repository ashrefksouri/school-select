01 — Méthode

Une ligne éditoriale claire, des sources officielles.

Pas de classement, pas de notation, pas de partenariat caché. Chaque école est traitée comme un objet éditorial documenté.

01

Sources officielles uniquement

Les 17 écoles sont vérifiées par cross-référence dans les registres officiels : AEFE pour les écoles françaises, IBO pour les écoles IB, Cambridge International pour les britanniques. Mise à jour trimestrielle.

02

Aucune notation, aucun classement

School Select ne note pas, ne classe pas, ne juge pas. Nous documentons les faits : curriculum, accréditations, niveaux, langues. Vous gardez le pouvoir de décision.

03

Sans biais commercial

Aucune école n'est mise en avant contre rémunération dans les résultats du quiz ou les recommandations. Les partenaires éditoriaux sont identifiés explicitement par un badge.

03 — L'approche

Trois outils pour orienter votre décision.

L'annuaire recense les 17 écoles privées internationales opérant en Tunisie en mai 2026, avec leur curriculum, leurs niveaux enseignés, leurs langues, leurs accréditations officielles. C'est la base de référence factuelle.

Le quiz d'orientation aide les familles à identifier les écoles les plus alignées avec leurs critères : niveau de l'enfant, gouvernorat, curriculum recherché, langues, accréditation. L'algorithme est transparent et expliqué.

Le comparateur permet de placer jusqu'à 4 écoles côte à côte sur tous les critères factuels : programme, langues, accréditations, frais (quand communiqués), localisation.

Trois outils, une logique

  • Annuaire — Explorer le catalogue avec filtres avancés
  • Quiz — 8 questions, filtres transparents, écoles compatibles expliquées
  • Comparateur — 4 écoles side-by-side sur tous les critères

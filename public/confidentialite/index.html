Politique de confidentialité.

School Select respecte votre vie privée. Cette politique détaille les données collectées, leur usage, leur durée de conservation et vos droits.

01 — Données

Données collectées.

School Select collecte uniquement les données strictement nécessaires au fonctionnement éditorial du site :

  • Données de navigation anonymisées — pages consultées, durée de visite, type d'appareil. Ces données sont agrégées et ne permettent pas de vous identifier individuellement.
  • Données volontairement transmises — si vous remplissez un formulaire de contact ou de demande d'information vers une école, les données saisies (nom, email, téléphone, message) sont collectées dans le seul but de traiter votre demande.

Nous ne collectons pas de données sensibles (origine, opinions politiques, religieuses, santé, etc.) sauf si vous nous les communiquez volontairement dans le cadre d'un échange.

02 — Usages

À quoi servent vos données.

Les données collectées sont utilisées pour :

  • Améliorer le service — comprendre quelles écoles et quelles informations intéressent les visiteurs pour prioriser les mises à jour éditoriales
  • Traiter les demandes d'information — transmettre votre demande à l'école que vous avez identifiée, si vous l'avez explicitement demandé
  • Répondre à vos questions — si vous nous contactez directement

Vos données ne sont jamais vendues, louées, échangées ou cédées à des tiers à des fins commerciales.

03 — Cookies

Cookies & traceurs.

Le site utilise un nombre minimal de cookies, dont :

  • Cookies techniques essentiels — nécessaires au fonctionnement du site (mémorisation de la langue, préférences d'affichage)
  • Cookies de mesure d'audience anonymisée — pour suivre la fréquentation agrégée du site, sans identifier les visiteurs individuellement

Aucun cookie publicitaire ni cookie tiers à finalité de profilage n'est déposé. Vous pouvez configurer votre navigateur pour refuser les cookies, sans que cela n'affecte significativement votre expérience.

04 — Tiers

Partage avec des tiers.

Si vous soumettez un formulaire de demande d'information à une école spécifique, les données saisies sont transmises à cette école uniquement, à votre demande explicite. School Select agit alors comme intermédiaire éditorial.

Aucune autre transmission de données à des tiers n'est effectuée, hors obligations légales (réquisition judiciaire, etc.).

05 — Vos droits

Vos droits.

Conformément aux législations applicables en matière de protection des données personnelles, vous disposez à tout moment d'un :

  • Droit d'accès — savoir quelles données vous concernant sont détenues
  • Droit de rectification — demander la correction de données inexactes
  • Droit de suppression — demander l'effacement de vos données
  • Droit d'opposition — refuser que vos données soient traitées pour certaines finalités
  • Droit à la portabilité — récupérer vos données dans un format structuré

Pour exercer ces droits, écrivez à contact@schoolselect.online. Une réponse sera apportée sous 30 jours maximum.

06 — Conservation

Durée de conservation.

Les données de navigation anonymisées sont conservées pendant 13 mois maximum, conformément aux recommandations européennes.

Les données de contact volontairement transmises sont conservées pendant la durée nécessaire au traitement de votre demande, puis pendant 3 ans pour des raisons de continuité éditoriale (suivi de relances, statistiques internes anonymisées). Vous pouvez demander leur suppression à tout moment.
